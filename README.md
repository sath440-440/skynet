# Skynet: TI Sensing Robot

Mecanum-wheel robot with a 3-DOF arm that demos TI sensing, wireless, motor drive and power parts working together. Drive it from a phone app, see live sensor data, and it docks itself to charge.

| Folder | What goes there |
|---|---|
| `firmware/` | Main MCU code (MSPM0G3507) |
| `connectivity/` | Wi-Fi/BLE (CC3551E) and the communication protocol |
| `sensing/` | Temp, humidity, light, battery and obstacle sensors |
| `motor-drive/` | Motor drivers, mecanum steering, wheel speed |
| `robotic-arm/` | 3-DOF arm |
| `power/` | Battery, charging, charging station |
| `navigation/` | Return-to-home and docking |
| `app/` | React Native phone app |
| `mechanical/` | Chassis and CAD |
| `test/` | Test plans and results |
| `docs/` | Slides, BOM, guides, notes |
